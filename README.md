# Study Guides

Published, phone/browser-friendly mirror of the study guides generated by the `study-guide-maker`
Claude Code skill. Static HTML, no build step, hosted on GitHub Pages.

**Live site:** https://fremen432.github.io/StudyGuides/

## This repo is a mirror, not the source

Guides are authored and updated in `C:\vc\workshop\study-guides\` (private, syncs across
machines via the `vc-workshop` repo). This repo exists only to publish that content somewhere a
phone browser can actually reach — it does not get hand-edited directly.

To pull the latest guides from the working copy and publish them:

```powershell
.\sync-from-workshop.ps1
```

Adding a brand-new guide also needs one manual step: add a card for it to `index.html` (see the
script's own doc comment for why that part isn't automated).

## Repo map

| Path | Purpose |
|---|---|
| `index.html` | Landing page — card grid linking to every guide |
| `*.html` | The guides themselves, one file each |
| `assets/` | Shared `style.css` / `script.js` every guide links to |
| `images/` | Supporting photos/diagrams, one subfolder per guide |
| `sync-from-workshop.ps1` | Pulls the latest guides from the private working copy and publishes |

## Why public

GitHub Pages on the free tier requires a public repo. The content isn't sensitive (study
material, not personal data), so this repo is kept separate from `vc-workshop` (which has
genuinely private notes) specifically so only the guides go public.
